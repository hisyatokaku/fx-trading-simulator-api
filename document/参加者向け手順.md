# 参加者向け手順

## 1. ログイン

1. ブラウザで **http://35.243.84.187** を開く
2. **ユーザー名**：運営から配られた ID を入力
3. **パスワード**：初回は **自分で決めたもの（7 文字以上）** を入力する。その場で登録され、**2 回目以降も同じパスワード**を使う
4. 「Start My Server」が自動で進み、JupyterLab が開く

> ID を間違えると「Invalid username or password」になります。パスワードを忘れた場合は運営に連絡してください（リセットします。作業ファイルは消えません）。

## 2. ノートブックを開く

左のファイル一覧に最初から入っています。

| ファイル | 用途 |
|---|---|
| `tutorial.ipynb` | Day 1：API の使い方チュートリアル |
| `colab_template.ipynb` | Day 2：戦略作成のテンプレート |

ダブルクリックで開き、上から順にセルを実行（`Shift + Enter`）。API の接続先は環境変数で設定済みなので、**URL の書き換えは不要**です。

## 3. 保存

- 編集内容は自動保存されます（`Ctrl/Cmd + S` で手動保存も可）
- ファイルは自分専用のホームに置かれ、他の参加者からは見えません
- 手元に残したい場合はファイルを右クリック → Download

## 4. 困ったとき

| 症状 | 対処 |
|---|---|
| 「Kernel died / restarting」 | メモリ上限（1 GB）を超えました。一度に読み込むデータを減らしてください |
| 「Disk quota exceeded」 | ディスク上限（2 GB）を超えました。不要なファイルを削除してください |
| セルが終わらない | 上部メニュー Kernel → Interrupt。それでも駄目なら Kernel → Restart |
| 画面が固まった | ブラウザを再読み込み。実行中のカーネルは残っています |
| ログインできない・パスワード忘れ | 運営に連絡 |

## 5. 終わるとき

右上 File → Log Out。共有 PC の場合は必ずログアウトしてください。
