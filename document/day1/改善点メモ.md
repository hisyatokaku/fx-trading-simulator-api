# Day1 教材の改善点メモ

最終更新: 2026-09-10

## 1. day1 から Day2 用の TEST データが覗ける

- day1.ipynb は Part 1 で `TEST0`（cell 9, 16）、発展課題 C で `TEST1`（cell 35）を使っている。
- TEST0〜18 は Day2 の訓練シナリオなので、Day1 の時点で参加者が Day2 で使うレート系列を見て戦略を作り込めてしまう。
- 対処案:
  1. day1 の実データ例を TUTORIAL か、Day2 で使わない専用シナリオに差し替える
  2. 発展課題 C の TEST1 への言及を外す
  3. 許容するなら、Day2 の説明で「TEST は練習用で評価には使わない」と明示する

## 2. 発展課題 B「seed を変えて別の系列を生成」が実行できない

- シナリオ 1〜3 の価格系列は `scripts/generate_tutorial_scenarios.py` が seed=42 で事前生成し、TUTORIAL1/2/3 としてサーバに登録したもの。
- 現行の day1.ipynb には乱数生成コードもローカル実行関数も無く（Part 2 で API 経由に統一）、参加者は seed を変えられない。ノートブック内で生成していた旧版の文言が残っている。
- 対処案:
  1. seed 違いの検証用系列（例: TUTORIAL2B）をサーバに追加し、B を「TUTORIAL2 で w, k を最適化 → TUTORIAL2B に同じパラメータを当てる」に書き換える（推奨。参加者の操作は既存 API のまま）
  2. 「最適化したパラメータを実データ（TEST）に当てる」に書き換える（追加データ不要だが、人工データと性質が違いすぎて過剰最適化の教材としては粗い）
  3. 生成関数とローカル実行関数をノートブックに戻す（API を使わない経路が増えて構成が複雑になる）
