## 5. 設定変更のやり方（必要になったとき）

### 5-1. ユーザーを消す
Admin パネルから削除（Hub の DB から消える）。Linux ユーザーとホームは残るので、消すなら VM で
`sudo userdel -r jupyter-<id>`（**成果物が消える。慎重に**）。削除スクリプトは事故防止のため置いていない。

### 5-2. ユーザー毎の上限を変える（無停止）
```
sudo tljh-config set limits.memory 2G
sudo tljh-config set limits.cpu 2
sudo tljh-config reload hub
```
反映されるのは**その後に起動したサーバーだけ**。動作中の人は Admin パネルで Stop → 本人が再 Start。

### 5-3. VM のサイズを変える（停止が必要・URL は不変）
55 人 × 2GB = 110GB は現 VM（64GB）を超えるので、上限を 2G にするなら VM も上げる。
```
gcloud compute instances stop fx-tljh --project=fx-itnern --zone=asia-northeast1-b
gcloud compute instances set-machine-type fx-tljh --project=fx-itnern --zone=asia-northeast1-b --machine-type=e2-highmem-16
gcloud compute instances start fx-tljh --project=fx-itnern --zone=asia-northeast1-b
```
その後 5-2 で `limits.memory 2G`。`config.sh` と `04` の値も合わせて直す。

### 5-4. 収容人数の目安（現行 e2-highmem-8 / 128GB）
| | 55 人最大時 | 上限 |
|---|---|---|
| メモリ | 55GB | 64GB（OS+Hub 約 3GB） |
| ディスク | 110GB | 128GB（OS+TLJH 約 8GB） |
| CPU | — | 同時に重い処理 8 人まで快適 |
