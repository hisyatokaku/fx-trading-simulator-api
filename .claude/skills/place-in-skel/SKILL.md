# 教材を /etc/skel に置く

TLJH の `/etc/skel` は、新規ユーザーの初回ログインでホームが作られる瞬間に中身が
コピーされる雛形ディレクトリ。ここに教材を置くと、**これから初回ログインする参加者
（まだログインしていない人）**のホームに自動で入る。

## いつ使うか

- 未ログインの参加者（本番 60 名など）に教材を配りたい
- `day1/` のように**ディレクトリごと**配りたい
- 既にログイン済みの人には触れず、新規ログイン者だけに配りたい

（既にログイン済みの人にも配りたい単一ファイルは `07_distribute_notebook.sh` を使う）

## 手順

`infra-setup/10_place_in_skel.sh` を実行する:

```
bash infra-setup/10_place_in_skel.sh <ローカルのパス>
```

- 例: `bash infra-setup/10_place_in_skel.sh document/day1`（ディレクトリごと）
- 例: `bash infra-setup/10_place_in_skel.sh document/day2/day2.ipynb`（単一ファイル）
- ファイル/ディレクトリ・日本語名・階層はそのまま保持される
- 配布元は**このローカルマシンの git ファイル**（gcloud 認証もローカルのもの）

## 注意

- 既に `/etc/skel/<名前>` がある場合は誤上書き防止のため中断する。
  置き換えたいときは、運営が VM 上で先に手動削除してから再実行する
- **既にログイン済みのユーザーには効かない**（skel は新規ホーム作成時のみ）。
  その人たちに配るには個別ホームへの配布が別途必要
- 配る前にローカルが最新か確認する（`git pull` で main を最新化してから配る）
