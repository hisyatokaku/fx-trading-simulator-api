# パスワードリセット（FirstUseAuthenticator）

TLJH 参加者が初回ログイン時に決めたパスワードを忘れた場合に、パスワードだけを
リセットする。ホーム・作業ファイルは消えない。

## 仕組み

FirstUseAuthenticator はパスワードを VM 上の `/opt/tljh/state/passwords.dbm` に保存する。
「キーが無ければ次回ログイン時に入力されたパスワードを新規登録する」動作なので、
dbm から該当ユーザーのキーだけ削除すれば、本人が次のログインで好きなパスワードを
再設定できる。

## 手順

`infra-setup/09_reset_password.sh` を実行する:

```
bash infra-setup/09_reset_password.sh <ID> [<ID> ...]
```

- `<ID>` は JupyterHub のユーザー ID（例: `tester-3`、参加者 ID `ckym3` など）。複数指定可
- 未ログイン（まだパスワード未設定）の ID は自動でスキップされる（リセット不要のため）
- 実行後は対象者に次を案内する:
  「もう一度 https://35-243-84-187.sslip.io にログインし、新しいパスワード（7 文字以上）を
   入力してください。それがそのまま新しいパスワードになります。作業ファイルは残っています。」

## 注意

- **パスワード本体は扱わない**: このツールは登録を消すだけで、パスワードを設定・表示しない
  （新パスワードは本人が次回ログインで決める）
- 冪等: 何度実行しても安全。既に未設定なら skip される
- 削除やユーザー再作成は不要（それは重い代替手段。このリセットで足りる）
